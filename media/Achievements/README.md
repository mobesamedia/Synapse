# Achievement assets

Each SVG is a complete 120 × 120 badge used directly by the Gamification sidebar.

Folders:
- `streak`: Study streak
- `reviews`: Reviews
- `days`: Study days
- `challenges`: Daily goals
- `comeback`: Welcome back

The four recurring achievements use `locked.svg`, `bronze.svg`, `silver.svg`, `gold.svg`, and `diamond.svg`.
The one-time comeback achievement uses `locked.svg` and `earned.svg`.

Keep the filenames and the `viewBox="0 0 120 120"` unchanged. You can otherwise organize and edit the SVG contents freely in your graphics editor. Restart Anki after replacing an asset so the WebView reloads it.
