# Local FreeMap icons

Source: https://github.com/lucide-icons/lucide/tree/66d8f9fc394b8530377e5f6112f0b8908ba01280

208 curated SVG icons. English category/tag metadata is supplemented
by SynapsePro’s selection.json. No network requests at runtime.

Build: `python3 scripts/build_map_icons.py lucide-66d8f9fc394b8530377e5f6112f0b8908ba01280.tar.gz`

SVG nodes are stored compactly in catalog.js and rendered as native SVG.
Original ISC/MIT notices are in LICENSE.txt and in exported maps using icons.
